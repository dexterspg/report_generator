Wireframe Notes

  • Step 1 (Configure) — configs persist in config/ folder. Upload once, reuse across sessions.
  • Replace vs Merge — Replace overwrites everything. Merge adds new entries + updates existing keys.
  • Download button — exports config as .xlsx for sharing between desktop users.
  • Step 2 (Upload CTR) — after file is selected, metadata is extracted and displayed.
  • Process button — disabled until both configs are set and CTR is uploaded.
  • The second "Step 2" card shows the file-selected state with extracted metadata.
  • After processing: results view with per-currency summary + download .xlsx output.

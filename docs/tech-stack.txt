DETAILED TECHNOLOGY STACK ANALYSIS
===================================

PRIMARY LANGUAGES
-----------------
- Python 3.x (backend application logic)
- JavaScript ES6+ (frontend application)
- Vue.js SFC (Single File Components)

BACKEND STACK
-------------
Framework & API:
  - FastAPI 0.104.1 (modern async web framework)
  - Uvicorn 0.24.0 (ASGI server with standard extras)
  - Starlette 0.27.0 (FastAPI foundation)
  - Pydantic 2.5.0 (data validation)

Data Processing:
  - Pandas 2.1.3 (Excel data manipulation)
  - NumPy 1.25.2 (numerical operations)
  - OpenPyXL 3.1.2 (Excel file handling)

Utilities:
  - python-multipart 0.0.6 (file upload handling)
  - email-validator 2.1.0 (validation)
  - python-json-logger 2.0.7 (structured logging)

FRONTEND STACK
--------------
Core Framework:

  - Vite 5.0.0 (build tool and dev server)

Libraries:

Build & Dev Tools:

PACKAGING & DEPLOYMENT
----------------------

Output Formats:
  - Windows executable (.exe)
  - Standalone desktop package (CTR_Mapper_Desktop_Package)
  - ZIP distribution (CTR_Mapper_Desktop_Package.zip)

CORE SERVICES
-------------

ExcelProcessor (services/excel_processor.py):
  - Main business logic for Excel processing
  - Reads input Excel files with pandas
  - Processes consolidated transaction reports
  - Generates formatted poliza ledger output
  - Handles company code filtering
  - Creates multi-file ZIP exports

FormulaMapper (services/formula_mapper.py):
  - Maps source Excel formulas to target format
  - Calculates exchange rates
  - Converts currency amounts
  - Builds GL account components

ENTRY POINTS
------------

Web Mode:
  python webapp/backend/app.py
  -> Runs on port 8000
  -> Serves SPA from frontend-dist/
  -> Stateless API server

Desktop Mode:
  python webapp/backend/app.py --desktop
  -> Runs on port 5000
  -> Auto-launches browser
  -> Same codebase, different configuration

Build Desktop Executable:
  python webapp/backend/build_desktop.py
  -> Creates dist/CTR_Mapper.exe
  -> Bundles frontend + backend + Python runtime
  -> Package: CTR_Mapper_Desktop_Package/

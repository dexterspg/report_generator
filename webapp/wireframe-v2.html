V2 Design Notes

Architecture Change

V1 was a single-page card layout. V2 introduces a sidebar + topbar shell with dedicated pages per feature: Process CTR, Account Mapping, Exchange Rates, History. This matches the backend's API surface and gives config management proper screen real estate.

New Components Needed

  • AppShell.vue — topbar + sidebar + router-view layout
  • SidebarNav.vue — navigation with active state + config badges
  • UploadSection.vue — drag/drop CTR upload with config readiness indicators
  • ResultsSection.vue — summary stats, sheet-tabbed preview table, download
  • ConfigPage.vue — shared layout for Account Mapping + Exchange Rates (table + upload split)
  • HistoryPage.vue — timeline view with rollback actions
  • ProcessingSection.vue — enhanced circular progress with step indicators

Typography

DM Sans for UI text (clean, geometric, not generic). JetBrains Mono for all data values, account numbers, file names, and status codes. Monospaced numerals with tabular-nums for column alignment in financial tables.

Color Strategy

Nakisa blue (#009cde) as sole accent. Neutral gray scale for surfaces. Financial green/red only in gain/loss columns. Status colors are desaturated (not traffic-light bright) for professional tone. Dark topbar anchors the brand identity.

Vue Router Required

V2 needs vue-router for page navigation. Routes: /process, /config/account-mapping, /config/exchange-rates, /history. The current v-if view switching should be replaced with proper routes.
